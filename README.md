# AUREA Skin Clinic

> Tu piel, sin filtros.

Beauty-tech aesthetic-clinic landing-page case study by Sara Duque.

**Live demo:** https://aurea-skin-clinic-landing.vercel.app

## Project
AUREA Skin Clinic is a fictional dermatology / aesthetic-medicine concept created to demonstrate conversion-focused UX/UI, responsive frontend development, accessibility, SEO and responsible health communication.

The landing is designed around one primary conversion goal: **Agendar valoración**. The experience intentionally avoids fabricated medical outcomes, testimonials, credentials, urgency, pricing and social proof.

## Visual direction
AUREA deliberately moves away from NOVA's luxury editorial real-estate language. The redesign uses a brighter beauty-tech system with geometric sans-serif typography, rounded modular cards, blush pink, lilac and mint accents, soft gradients, close-up skin photography and interface patterns that feel closer to a contemporary aesthetic clinic.

## Experience highlights
- Beauty-tech art direction designed specifically for an aesthetic clinic
- Pearl white, blush pink, lilac and mint palette
- Bold sans-serif hero instead of editorial serif composition
- Large skin-focused beauty imagery with floating assessment cards
- Three visual care categories: texture, tone and sensitivity
- Interactive skin check-in without automated diagnosis
- Four-step consultation journey
- Technology-with-criterion section framed around indication and context
- Transparency / portfolio-integrity block
- Booking form with validation and local success state
- No CRM, tracking, appointment system or personal-data storage in the demo
- Responsive layout, keyboard focus and reduced-motion support
- Production metadata, canonical URL and social metadata

## UX and accessibility
The interface prioritizes understandable health communication, visible focus states, semantic controls, responsive behavior, touch-friendly actions and reduced-motion handling. Interactive modules are orientation tools, not diagnostic systems.

## Medical / portfolio integrity
AUREA is a fictional portfolio concept. It does not represent a real clinic and does not provide medical advice, appointments or treatment recommendations.

The project intentionally does **not** fabricate:
- doctors or professional credentials
- patient testimonials
- treatment success rates
- before/after outcomes
- device claims or clinical evidence
- availability, prices or appointments

In a real implementation, these elements would require verified sources and applicable regulatory review.
